# 강원랜드 텍사스 홀덤 Next.js 프로젝트

이 프로젝트는 `AGENTS.md` 기준을 따라 강원랜드 텍사스 홀덤 규칙을 초보자도 확인할 수 있게 정리하고, 사람 1명과 컴퓨터 1~7명이 함께 플레이할 수 있는 웹 시뮬레이터로 구성했습니다.

## 실행

```bash
npm install
npm run dev
```

## 구현 범위

- `git init` 완료
- Next.js App Router 구조
- 사람 1명 + 컴퓨터 최대 7명
- 프리 플랍 (Pre-flop) → 플랍 (Flop) → 턴 (Turn) → 리버 (River)
- 스몰 블라인드 2,000원 / 빅 블라인드 5,000원
- 단계별 베팅 상한
  - 프리 플랍: 5,000 → 10,000 → 15,000
  - 플랍: 5,000 → 10,000 → 15,000
  - 턴: 10,000 → 20,000 → 30,000
  - 리버: 10,000 → 20,000 → 30,000 → 40,000(캡)
- 1인 기준 최대 베팅 100,000원
- 쇼다운 후 수수료 5% 차감 정산

## 주의

- 제공된 기준에는 사이드 팟, 올인, 좌석별 세부 카지노 운영 규칙이 명시되어 있지 않아 추가하지 않았습니다.
- 카드 서열 표시는 `AGENTS.md` 기준을 유지했습니다.
- 원문 카드 서열에는 하이 카드가 없지만, 화면 내부 승패 판정에는 예외적으로 보조 비교 값이 사용됩니다.
